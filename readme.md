# Didactic Jesus Game — Demo (Android)

Free demo of the RPG Maker MZ game: a trimmed copy of the full version (27 maps),
published on Google Play only.

- Package name: `com.biblegamesproject.didacticjesusgame`

It is managed from bgp-admin. The full version lives in
[didactic-jesus-game-ios](https://github.com/Bible-Games-Project/didactic-jesus-game-ios) and
[didactic-jesus-game-android](https://github.com/Bible-Games-Project/didactic-jesus-game-android).

`bun run build` copies the game into `dist/`. There is no other build step.

The history before the move to this organization comes from `biblegamesproject/didactic-jesus-game-demo`.
